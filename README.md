# 🎬 OTT Streaming Content Trend Analysis

## 📌 Project Overview

This project analyzes OTT (Over-The-Top) streaming content catalogs to understand patterns in movies, TV shows, genres, release years, countries, content ratings, and movie durations.

The project was developed as part of the **Veda Technology Data Analytics Internship – Day 35**.

## 🎯 Objectives

- Analyze OTT content distribution by platform.
- Compare movies and TV shows.
- Identify frequently listed genres.
- Explore content release-year trends.
- Analyze country-wise content distribution.
- Visualize content ratings and movie durations.
- Build an interactive dashboard with filters.
- Generate data analysis reports and downloadable files.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- IPyWidgets
- SQLite
- Excel
- Google Colab

## 📊 Visualizations

The project includes nine types of charts:

1. OTT platform distribution
2. Movie vs. TV show distribution
3. Genre popularity
4. Release-year trends
5. Country-wise content distribution
6. Content rating distribution
7. Movie duration distribution
8. Platform-wise content comparison
9. Content distribution by release decade

## 📈 Interactive Dashboard

The Google Colab dashboard includes filters for:

- Platform
- Content type
- Genre
- Release year

Users can change the filters to explore different subsets of the catalog.

## ⚠️ Dataset Note

Demo data is used when a real dataset is unavailable. Demo data is illustrative and must not be treated as actual OTT platform statistics.

For meaningful real-world findings, use a verified public OTT catalog dataset and document its source.

Catalog counts do not represent actual viewership, subscriber numbers, or streaming popularity.
